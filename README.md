## 📖 About The Project

**Atmos** is a minimal and modern weather dashboard built using HTML, CSS and Vanilla JavaScript.

The project focuses on presenting weather information through a clean interface with carefully balanced spacing, typography and a simple colour palette.

It was developed as part of the **Skill Me Internship Program – Week 1 Task**, focusing on building a static weather application layout using sample weather data.

The application includes a search interface, a current weather overview and a seven-day forecast.

## ✨ Features

- 🔍 **City Search:** Search supported cities using the search bar.
- 🌡️ **Current Weather:** Displays temperature, weather conditions and feels-like temperature.
- 💨 **Wind Speed:** Shows sample wind speed information.
- 💧 **Humidity:** Displays humidity percentage.
- 📅 **7-Day Forecast:** Displays daily weather conditions with maximum and minimum temperatures.
- 📱 **Responsive Design:** Optimized layouts for desktop, tablet and mobile devices.
- 🎨 **Customizable Theme:** Centralized CSS variables for easy colour customization.
- ⚡ **Lightweight:** Built without external frameworks or dependencies.

## 🚀 Getting Started

Follow these steps to run the project locally.

### 1. Clone the repository

```bash
git clone YOUR_REPOSITORY_URL
```

### 2. Navigate to the project folder

```bash
cd atmos-weather-dashboard
```

### 3. Run the application

Open `index.html` in your browser.

**Recommended:** Use the Live Server extension in Visual Studio Code for a better development experience.

## 🎨 Customization

The application uses CSS custom properties to manage its colour palette.

You can change the entire theme by editing the `:root` section in `style.css`.

```css
:root {
    --bg-primary: #F5F6F8;
    --bg-card: #FFFFFF;
    --color-primary: #253D5B;
    --color-accent: #6688AB;
    --text-primary: #202C3A;
    --text-secondary: #788594;
    --border-color: #E7EBF0;
}
```

## 📱 Responsive Design

Atmos is designed to work across different screen sizes.

- 💻 Desktop: Spacious weather dashboard with seven forecast cards in one row.
